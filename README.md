<h1># # IT-Ticket-Slow-PC</h1>
Here im simulating receiving an IT ticket for a employee claiming their PC is moving too slow and diagnosing and solving the issue.




<h2>Environments and Technologies Used</h2>

- Microsoft Azure (Virtual Machines/Compute)
- Remote Desktop
- Spiceworks Cloud Help Desk Software

<h2>Operating Systems Used </h2>

- Windows 11
- Windows Server 2025 Datacenter
